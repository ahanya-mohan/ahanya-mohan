### 🩺 [covid-plus](https://github.com/ahanya-mohan/covid-plus)

### 🛡️ [web_vul_scanner](https://github.com/ahanya-mohan/web_vul_scanner)

An educational **web vulnerability scanner**: crawls a target, probes its inputs
for **SQL injection** and **reflected XSS**, and reports findings with
remediation. Ships a from-scratch **Naive Bayes phishing-URL classifier** and a
Django UI. _Authorized-use only; bundles a safe practice target._

**Python · Django · Naive Bayes · pytest · GitHub Actions**
